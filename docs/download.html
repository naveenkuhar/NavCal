Download Navcal

For any Linux distribution with Flatpak. Navcal is free, and always will be.

Download the Flatpak Source Code
  • Linux with FlatpakIncluded with most distributions that come with GNOME.
  • GNOME’s calendar serviceComes with GNOME; it keeps your calendars in sync.
  • About 2 MBPlus GNOME’s runtime, which comes from Flathub by itself.

Install

It takes a minute. The first time, Flatpak also downloads GNOME’s runtime, which other GNOME apps share.

  1. Download the file

    Get navcal-0.6.0.flatpak from the latest release.

  2. Install it

    Open the file with Software, or run this in a terminal from the folder you saved it to:

    flatpak install --user navcal-0.6.0.flatpak

    If Flatpak asks to add Flathub for the runtime, say yes.

  3. Open Navcal

    Find Navcal among your apps, or run:

    flatpak run io.github.navcal.Navcal

    New here? The User Guide shows you around.

No Flatpak yet? Flathub has instructions for every distribution.

Update

Download the new file and install it the same way. Your events and settings stay as they are.

Uninstall

flatpak uninstall io.github.navcal.Navcal

Add --delete-data to remove Navcal’s settings too. Your events stay in your calendars either way.

Build It Yourself

Navcal is free software: you can read, change and share its code under the GNU GPL, version 3 or later.

As a Flatpak

You’ll need the Flatpak builder and the GNOME SDK, a one-time download of about 1 GB. The build script installs Navcal for you and makes a .flatpak file to share.

git clone .git navcal
cd navcal
flatpak install --user flathub org.flatpak.Builder org.gnome.Sdk//50
tools/build-flatpak.sh

From the source folder

To work on Navcal, run it straight from the source with uv. It uses your system’s GTK, so install that first (these are the Fedora names; all of them come with Fedora Workstation):

sudo dnf install python3-gobject gtk4 libadwaita evolution-data-server
uv venv --python /usr/bin/python3 --system-site-packages .venv
uv sync
uv run navcal

The tests run with uv run pytest. The CONTRIBUTING.md file in the source explains how to test and change Navcal, and the design rules it follows.

For distributions

Navcal builds and installs with Meson:

meson setup build
meson install -C build

If Something’s Not Right

Flatpak says the runtime wasn’t found

Add Flathub, where GNOME’s runtime comes from, then install Navcal again:

flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
My calendars don’t show up

Navcal shows the calendars of GNOME’s calendar service (evolution-data-server), which comes with GNOME. Add your accounts in Settings → Online Accounts, and check that the calendars are switched on in Preferences → Calendars.

Reminders don’t come when Navcal is closed

Turn on Run in background and Start at login in Preferences. Closing the window then keeps Navcal running, hidden, and it starts by itself when you log in.

There’s no weather under the dates

In Preferences → Weather and Places, set your place, and check that Look up places and weather online and Show weather are on. The forecast covers about the next two weeks.

My events don’t appear in the Activities search

GNOME Shell looks for search providers when you log in, so log out and back in once after installing Navcal.

What’s New

Navcal 0.6.0

September 27, 2026
  • Weather: the forecast under each date with the day’s high and low, in °C or °F, and the weather now in the bottom bar.
  • Places: address suggestions while typing, the forecast for when an event starts, and opening hours, with a warning when a place is closed or closes before the event ends.
  • Printing: a live preview, with a calendar, an agenda or both side by side, to print or to save as an image.
  • Bottom bar: choose what it shows and in what order.
  • Drag and drop: hold Ctrl to duplicate, with a faded copy under the pointer; moved events no longer jump back for a moment.
  • Zoom: pinch, or scroll with Ctrl held, to zoom the hours.
  • Travel time: Custom… takes any number of minutes.
  • Sidebar: dots under the days with events, and long lists fold after five items.
  • Speed: much faster with large calendars — moving around takes milliseconds, and imports are dozens of times faster.
  • Install: Navcal now comes as a Flatpak.
